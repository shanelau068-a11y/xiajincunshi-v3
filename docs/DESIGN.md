# 重新设计说明

目标是让乡亲在手机上打开即读，把一本扫描识别的村史转为清楚、亲切、便于查找的阅读网站。

采用米白纸色、深绿墨色和小面积赭色，以宋体标题与正文形成书籍感。首页封面单独保存在 `public/media/cover/`。封面与旧影中的补充村落照片都不写具体地点：村史原文没有把这一画面定在某一处。寻旧影共77张（75张扫描、1张辈序牌匾、1张补充村落旧影）。原书扫描图库保留原有出处与名称。

首页四个入口为读村史、寻旧影、看春秋、访乡贤。手机固定底栏为首页、读村史、搜索、族谱、书签；寻旧影、看春秋、访乡贤从首页进入。桌面使用横向导航与阅读侧栏。

阅读器提供章节目录抽屉、字号调整、夜间模式、书签、进度恢复和分享。全文搜索按真实资料匹配，展示上下文，并返回原文定位。

新站保留原书资料和原有整理内容，明确区分书中原文与后期校对意见。人物不伪造头像，不从任官年份推算生卒年；照片保留扫描出处与待校对提示；不呈现示例地图或推测世系。
